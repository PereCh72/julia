# JULIÀ

Aquest repositori conté el guió de l'obra de microteatre "Julià", una història sobre el destí, el karma i la mort.

L'obra explora la fragilitat de la vida, el pes de les nostres decisions i la complexitat de l'amistat a través d'una conversa aparentment quotidiana entre dos amics en una sala de vetlla, que culmina amb un gir final del tot inesperat.
